# Docs index for agents

Open a doc only when its trigger matches your task. Skills and agent definitions already name the docs their workflows need.

- **Concepts** — `concepts.md`. Read when you need the meaning of Action, Handler, Preset, WM/ER or Environment.
- **Configuration** — `configuration.md`. Read when reading or changing `pyproject.toml` configuration, environment variables or CLI flags.
- **CLI reference** — `cli.md`. Read when changing or invoking `run`, `prepare-envs`, `dump-config`, `start-lsp` or `start-mcp`.
- **Creating an extension** — `guides/creating-extension.md`. Read when creating a new extension package.
- **Designing actions overview** — `guides/designing-actions.md`. Read when designing an action and unsure which of the two docs below applies.
- **Designing actions rules** — `guides/designing-actions-rules.md`. Read when designing or reviewing an action, handler or preset against the normative rules.
- **Designing actions guide** — `guides/designing-actions-guide.md`. Read when an action spans languages, needs language-specific subactions, or its specificity level is unclear.
- **Designing services rules** — `guides/designing-services.md`. Read when adding or changing a service, or choosing between an init action and service config.
- **Creating a preset** — `guides/creating-preset.md`. Read when creating or changing a preset.
- **Preparing environments** — `guides/preparing-environments.md`. Read when changing environment preparation, the `dev_workspace` bootstrap, or environment filtering.
- **Developing FineCode** — `guides/developing-finecode.md`. Read when implementing changes in this repo: structure, setup, checks, logging policy, lock files, code style.
- **WM server internals** — `guides/wm-server-internals.md`. Read when changing WM server code: layers, services, run service, key flows, error conventions.
- **Built-in actions reference** — `reference/actions.md`. Read when you need the contract of a built-in action.
- **Why the Action Model works** — `theory/why-action-model.md`. Read when you need the rationale or practical guarantees behind the action model.
